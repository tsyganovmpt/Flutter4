# Практическая работа №2 - приложение «Заметки»

## Реализованные возможности

- Добавление заметок.
- `onTap` — просмотр полного текста заметки.
- `onDoubleTap` — переключение отметки важности (звезда и цвет карточки).
- `onLongPress` — редактирование заметки; после сохранения текст обновляется.
- Свайп влево — удаление заметки (`Dismissible`).
- Свайп вправо — снятие отметки важности; карточка остаётся в списке.

## Запуск

1. Откройте папку проекта `Flutter2-main` в Android Studio или VS Code.
2. Выполните `flutter pub get`.
3. Запустите приложение командой `flutter run` или через IDE.

## Проверка жестов

1. Добавьте заметку и коротко нажмите на неё - откроется полный текст.
2. Дважды быстро нажмите на карточку - она станет жёлтой и появится звезда.
3. Удерживайте карточку - откроется окно редактирования.
4. Смахните карточку влево - заметка удалится.
5. Создайте новую заметку, отметьте её двойным нажатием и смахните вправо - звезда исчезнет, карточка останется.
